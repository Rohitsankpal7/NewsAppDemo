# 📰 iOS News App  

An iOS application that fetches and displays the latest news articles using `Combine` and `SwiftUI`. This app follows **MVVM architecture** and integrates **unit testing** with `XCTest`.

## 📌 Features
- Fetches real-time news from an API using `Combine`.
- Displays news articles in a **grid layout**.
- Uses `AsyncImage` for loading remote images.
- Implements **unit tests** for `NewsViewModel` and `NetworkService`.
- Used MVVM design pattern with combine.
